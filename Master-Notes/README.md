## How to revise

1. Read the concept and why it matters.
2. Trace the code and predict its output before running it.
3. Compare your result with the expected output.
4. For visualization, explain what each graph tells you.
5. Review the ML connection and common mistakes.

## Scope

The goal is to support classical ML and provide useful foundations for deep learning. For ML workflows, remember: split data first; fit learned preprocessing only on training data; apply the same fitted transformation to validation/test data.

**Style:** Simple English · Balanced explanations · Small and real-world examples · Expected outputs · Visual graph references · Tips, pitfalls and quick revision.
